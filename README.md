# 트릭컬 레코드

트릭컬 리바이브의 **차원 대충돌, 엘리아스 프론티어 등 레이드 콘텐츠 상위 300위 랭킹**을 시즌별로 집계하고, 사도 통계와 사복 정보, 교단 계산 등 여러 기능을 제공하는 비공식 팬 사이트입니다.

**서비스:** https://trickcalrecord.pages.dev/

> 게임 이미지와 명칭 등의 저작권은 EPIDGames에 있습니다.
> 
> 집계된 모든 데이터는 게임 내 레이드 콘텐츠별 **랭킹**에서 확인할 수 있습니다.


## 주요 기능

- **시즌별 집계:** 열별 픽률, 성격 분포, 인기 조합, 인기 사복, 점수·클리어 시간·코인 분포 등
- **사도별 통계:** 특정 사도의 레이드 콘텐츠별 1위 기록, 사복 사용 현황, 콘텐츠별 추이
- **사복:** 사복의 성격별 출시 기록, 사도별 사복 현황 (`/costume`)
- **콘텐츠 타임라인:** 레이드 콘텐츠 및 사도 출시 일정 (`/timeline`)
- **교단 계산:** 교단 시설 업그레이드 비용 및 연구 비용에 필요한 재료와 모험(아르바이트) 횟수 계산 및 안내 (`/sim`)


## 데이터

게임 내 랭킹 상세 화면의 상위 300위 기록을 수집해 `public/data/`에 저장합니다.

> 데이터 수집 및 json 생성은 아래 프로젝트에서 진행합니다.
> 
> https://github.com/lsbim/t-r-c-f

- 2025-06-12 이후 직접 집계한 데이터와 이전 데이터는(제보받은) `type: external|season`으로 구분합니다.


## 새 시즌 추가

- `public/data/{콘텐츠 폴더}/`에 `{시즌번호}.json`을 추가합니다. 베타 시즌의 경우 10000을 더하여 저장합니다.(10001, 10002...)
- 엘리아스 프론티어에서 새 보스나 단계가 생겼다면 보스 체력 정보(`bosses`)를 갱신합니다.
- 신규 사도나 사복이 있다면 `src/data/trickcalChar.ts`, `src/data/costumes.ts`를 갱신합니다.
